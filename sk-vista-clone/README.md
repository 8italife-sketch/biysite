## 🚀 БЫСТРЫЙ СТАРТ

### Шаг 1: Откройте `whitepaper-template.html`

Все места, требующие замены, отмечены **[СКОБКАМИ]**.

### Шаг 2: Заполните обязательные поля

#### 🔴 КРИТИЧЕСКИ ВАЖНО (заменить обязательно):

1. **Название компании**
   - Найти: `[НАЗВАНИЕ КОМПАНИИ]`
   - Заменить на: Ваше название (например, "СтройМонтажГрупп")

2. **Контакты**
   - Телефон: `[+7 (XXX) XXX-XX-XX]` → Ваш телефон
   - Email: `[email@company.ru]` → Ваш email
   - Адрес: `[Ваш адрес с индексом]` → Полный адрес офиса

3. **Логотип**
   - Заменить SVG в секции `<header>` на ваш логотип
   - Формат: SVG (предпочтительно) или PNG

4. **Meta-теги**
   ```html
   <title>Ваша Компания – Строительство объектов под ключ</title>
   <meta name="description" content="Ваше уникальное описание..."/>
   ```

5. **Карта**
   - Заменить координаты в iframe Яндекс.Карт
   - Получить код карты: https://yandex.ru/map-constructor/

6. **Формы**
   - Указать URL обработчика форм в `action="[URL_ОБРАБОТЧИКА]"`

#### 🟠 РЕКОМЕНДУЕТСЯ (для лучшего результата):

7. **УТП (Уникальное Торговое Предложение)**
   ```
   Заголовок: "Промышленное строительство под ключ в [Ваш город]"
   Подзаголовок: "Срок сдачи от 8 месяцев. Гарантия 7 лет. Работаем с 2010 года"
   ```

8. **Ключевые цифры**
   - Лет на рынке
   - Реализованных проектов
   - Сотрудников в штате
   - Срок гарантии

9. **Услуги**
   - Заменить названия и описания услуг
   - Добавить иконки для каждой услуги

10. **Портфолио**
    - Загрузить фото реальных объектов (минимум 6-10)
    - Добавить описание каждого проекта

11. **Цветовая схема**
    ```css
    :root {
        --primary-color: #2C5F2D;   /* Ваш основной цвет */
        --accent-color: #FFB400;    /* Ваш акцентный цвет */
    }
    ```

## 💡 СОВЕТЫ ПО КОНТЕНТУ

### Заголовки
- H1: Главный + УТП (до 60 символов)
- H2: Названия разделов (до 40 символов)
- H3: Подзаголовки карточек (до 30 символов)

### Тексты
- Кратко и по делу
- Избегайте клише ("динамично развивающаяся компания")
- Используйте цифры и факты
- Пишите о выгодах для клиента

### Фотографии
- Только реальные фото объектов
- Хорошее качество (минимум 1920x1080)
- Оптимизированный размер (WebP, до 200 КБ)

## 🔧 ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ

### Минимальные требования:
- HTML5 валидный
- Адаптивность (mobile-first)
- Скорость загрузки < 3 секунд
- HTTPS сертификат

### Рекомендуемые улучшения:
- Микроразметка Schema.org
- Open Graph теги для соцсетей
- Lazy loading для изображений
- PWA (Progressive Web App)
